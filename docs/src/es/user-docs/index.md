# Documentación para usuarios

`pk3s` es el ejecutable unificado para trabajar con Productive K3S Core y Productive K3S Infra.

No es la plataforma en sí: es la interfaz más simple y recomendada por encima de las capacidades reales de Core e Infra.

En esta sección se explica cómo instalarlo, cómo usar resolución local o remota de bundles, cómo trabajar con perfiles y cómo diagnosticar errores comunes.
